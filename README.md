# KINETIC Fitness Studio

Modern, dark-themed responsive web application for KINETIC Fitness Studio built with React and Tailwind CSS.

## Live Demo

Visit the live site here:
https://kinetic-fitnesss.netlify.app/

## Features

- Dynamic class schedules
- Trainer rosters
- Tiered membership plans
- Client intake registration
- Responsive dark-themed design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Netlify

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Project Overview

This app showcases a modern fitness studio website with a polished user experience, flexible scheduling, pricing tiers, and a streamlined client intake flow.
